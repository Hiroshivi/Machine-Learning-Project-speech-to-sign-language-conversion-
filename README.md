# Machine-Learning-Project-speech-to-sign-language-conversion-
A python based project which uses google translate API to covert speech to sign language 

To run this project first clone this repo then create a file then add both the images file and code file to that folder

Required dependencie to run this project : pip install SpeechRecognition pillow pyaudio

open your command centre and enter the pip command to install all the dependencies 

Run the project and make sure u speak clearly to conver the speech to text
